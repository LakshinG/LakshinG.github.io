Interactive simulation, not the Go binary. NovaKV is a Go server that talks gRPC and writes BoltDB files, which a browser can't run. This page reproduces its behavior in JavaScript, following the real server code: writes must go to the leader, reads work on any node, and each write commits once a majority has it. To run the real cluster, get the source and setup steps on GitHub.

NovaKV cluster

Three nodes replicate every write through Raft. Kill the leader and watch the other two elect a new one. Kill two nodes and writes stop, because there's no majority left to commit them.

Client

Works like cmd/client: pick a node's gRPC port and send a command.

TTL is optional. A background sweeper deletes the key when it expires, like Redis.
