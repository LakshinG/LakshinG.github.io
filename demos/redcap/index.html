Illustrative walkthrough on a fictional note. The real pipeline runs a 32B model on protected patient notes at the lab, so it can't be put online. This page walks through the project's actual steps on a made-up admission note with no real patient in it. The pass 1 summary and most field answers come from a test run with a smaller model (Qwen 2.5 7B). Fields that model got wrong were filled in by hand with the answer the codebook rules call for, so treat the values as an example of the output, not a benchmark. See the source on GitHub.

REDCap clinical note extractor

Research teams hand-copy details from clinic notes into REDCap forms. This pipeline reads the note, fills in the codebook fields, cites the sentence behind each answer, and outputs a CSV REDCap can import directly.
